# 森罗物语：家什（Kaleidoscope Kitchenware）

森罗物语：厨房的附属模组。补齐本体缺少的储物、水与排烟家具，并附上一整套中式厨房建材，让你把厨房真正搭成一个厨房。

- 目标版本：Minecraft 1.21.1 / NeoForge 21.1.x
- 前置：[森罗物语：厨房 Kaleidoscope Cookery](https://modrinth.com/mod/kaleidoscope-cookery) 1.6.0（可选依赖：不装本体时模组仍可启动，仅热源联动失效）

## 内容

**功能方块（7 个）**

| 方块 | 说明 |
| --- | --- |
| 柴火灶 | 投入燃料后可用打火石点燃，上方放本体的炒锅 / 汤锅 / 蒸笼 / 茶壶即可直接开火。燃料分文火（木板）、中火（煤炭）、猛火（烈焰粉）三档，影响燃烧时长与消耗速度。雨天无遮挡会自灭，烧尽自动熄灭 |
| 柴火堆 | 1 到 4 层的柴堆，可存可取，用尽即消失 |
| 烟囱 | 青砖立柱，接在灶上方做烟道，纯装饰 |
| 水缸 | 中式大水缸，四档水位外观。手持空桶或空瓶右键即可打水，默认作为无限水源 |
| 碗柜 | 16 格，只收碗与花盆。柜门会自己打开、几秒后合上 |
| 调料罐 | 玻璃合成的小罐，放置后像茶杯一样贴在台面上。可存 16 组任意物品，右键存取、无界面；手持本体的锅铲右键可整个铲起带走，里面的调料不丢 |
| 料理台 | 石面木身的工作台，并排摆开即成一条连续操作台 |

**建材方块（18 个）**

- 青砖组：青砖块、青砖台阶、青砖楼梯、青砖墙
- 青瓦组：青瓦块、青瓦台阶、青瓦楼梯、屋脊瓦
- 墙地组：抹灰墙、夯土墙、青石地砖、木地板
- 木构组：木梁、椽木、木格窗、竹帘

## 交互

**本模组没有任何容器界面。**所有存取都在世界里用鼠标完成：

| 操作 | 行为 |
| --- | --- |
| 手持物品**右键**罐子 | 把主手**整组**存进去 |
| **空手右键**罐子 | 取出**一整组** |
| **左键**罐子 | 取出**一个**（潜行时仍是正常挖掘） |
| 手持锅铲**右键**罐子 | 从罐里舀出一份 |
| 手持锅铲（带油）右键罐子 | 把油倒回罐里 |
| 手持锅铲（带调料）右键**炒锅** | 调料下锅 |
| 手持锅铲（带油）右键**炒锅** | 与搪瓷盆子的油完全一致（本体处理） |

反馈全部走动作栏文本与音效，看不到任何 GUI。

柴火灶：手持燃料右键投柴 → 打火石点燃 → 空手右键查看剩余燃料与当前火力档 → 手持锹或锅铲右键熄灭。

水缸：手持空桶或空玻璃瓶右键打水。

## 配置

`config/kaleidoscope_kitchenware-common.toml`

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `stove.fuelBurnMultiplier` | 1.0 | 燃料燃烧时长倍率 |
| `waterVat.consumesLevel` | false | 打水是否消耗水位（开启后缸空了需要拿水桶补） |
| `storage.cupboardCapacity` | 16 | 碗柜格数（上限 27） |

## 数据包扩展

碗柜的物品白名单走物品标签 `kaleidoscope_kitchenware:cupboard_storable`，默认包含 `minecraft:bowl` 与 `minecraft:flower_pot`。整合包作者可以通过数据包追加其他碗类或盆类物品。

## 构建

```bash
./gradlew build
```

开发环境需要把本体 jar 放到 `libs/kaleidoscopecookery-1.6.0.jar`（不随本仓库分发）。

本模组的贴图与模型由 `tools/gen_decor.py` 生成，风格规则见 skill `kaleidoscope-art-style`：

```bash
python tools/gen_decor.py      # 重新生成贴图与全部资源 JSON
python tools/check_resources.py # 自检：JSON 合法性、文件齐全、语言条目一致
```

## 已知限制

- 本体判定热源时只检查锅具正下方一格，因此一灶多锅与"火力档影响熟制速度"需要 Mixin 修改本体，本版本不做。
- 料理台目前是可平铺的台面方块，尚不能在台面上陈列物品。
- 未安装本体时可以正常启动与建造，只是柴火灶不再被任何锅具识别。
